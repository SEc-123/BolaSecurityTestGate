这里的 Web 靶场和 Android 文档服务都是实际启动的网络服务，产品通过真实浏览器、模拟器、APK、代理、原生测试执行器和模型桥接完成请求；它们是本地受控目标，并非已保存的外部站点或生产环境。Web 风险来自故意存在漏洞的上传/搜索接口；Android 风险来自受控文档接口允许账号 A 读取账号 B 对象。测试结果证明产品流程可用，不代表任何其他站点或 APP 有同样漏洞。

## 修复

- 产品投影依据持久化的 campaign 抽样计划，把未入选候选显示为“已跳过”，保留“未单独测试”的说明；已规划却未执行的候选仍显示“未执行”。只把候选 ID 投影给用户视图，避免暴露规划文本或账号材料。
- Android 发现阶段导入流量后会结束采集会话。后续候选规划和漏洞子任务现在按已捕获接口执行原生工具，并在完成后结束；不再让模型重新打开已关闭会话或把场景采集切换成自动探索。原生执行器的漏洞判断仍使用已配置模型。
- Web 验收同时核对已选任务全部完成、抽样候选明确跳过，以及无待复核/未执行项，避免仅凭整轮 `completed` 状态宣称通过。
