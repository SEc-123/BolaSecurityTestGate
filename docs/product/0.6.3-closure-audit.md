## 独立模型桥接

桥接位于独立项目 `/Users/a0000/Documents/LocalAstraBridge`，不是 BSTG 的源码、依赖或内部服务。BSTG 仅保存标准 OpenAI-compatible provider 配置。

- 仅监听 `127.0.0.1:19447`，需要本地独立 API key。
- 通过已安装且已登录的 Codex app-server 调用，固定并核对实际 `gpt-6-astra`、`xhigh`；禁止模型回退。
- 每次调用是独立临时线程，无环境工具；不修改用户主 Codex 配置。
- 已完成两次普通真实推理连接验证，保存上游回执、模型、推理强度及用量；这不是安全测试通过的证据。
- 独立 LaunchAgent 已安装；BSTG 启停不控制该服务。
- 上游安全权限拒绝返回 HTTP 403；桥接不重写被拒绝的请求。

权限须在对应账户、模型和访问入口中实际生效，不能从模型列表可见推断获得安全测试权限。参考 [OpenAI Models and Trusted Access](https://learn.chatgpt.com/docs/cyber-safety)。

## 产品修复

1. 缺少 provider、认证失败、权限拒绝或模型决策失败时停止本轮，删除“模型失败后仍按本地策略执行”的降级路径。
2. 401/403 等永久失败不盲目重试；网关包装为 502 的明确策略拒绝同样停止。HTTP 200 中的模型 refusal 也按拒绝处理。JSON 格式兼容重试不能覆盖安全拒绝。
3. 有效 AI 决策保存实际响应模型、上游回执 ID 和用量。Web / Android 完整验收脚本必须提供真实 provider，并核对实际模型决策，不能无模型跑通后称为 AI 验收。
4. 账号配置加入可选 HTTPS 统一登录来源，最多 8 个；重试可补充该来源并保留原账号和 URL。只有返回目标来源、观察到实际会话变化才记录登录成功。
5. 使用 Chromium 请求拦截检查重定向链的每一跳，保留第一处失败原因；通用交互工具不能操作仅允许登录的来源。
6. **弹窗首次导航当前明确不支持**。浏览器接口在其首个请求后才暴露 Page/Frame，无法可靠保护整条重定向链；因此在首次请求发出前阻止并提示使用当前窗口登录。主页面登录和重定向已通过实际浏览器验证。
7. 本地启动器可保存模型超时和推理强度，重启不会丢失 600 秒 / xhigh 配置。模型设置验收使用动态端口，避免与独立桥接冲突。
