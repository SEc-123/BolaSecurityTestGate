# 0.6.5 Luna 调用与真实 Web 失败修复

本次开发以 BSTG `bf46964` 为基线，保留原主目录已暂存的 0.6.4 变更及用户 `.opencode/`。独立桥接以 `979d533a4feec8577218f62d17cb82c225b93bc3` 为基线，代码和运行数据仍在其独立仓库。本版本只做本地交付，不推送远端。

## 真实执行结果

桥接与原有 BSTG provider 已实际使用 `gpt-6-luna / xhigh / openai`，模型回退关闭，provider ID 与密钥保持不变。真实 app-server 无提示探针和 BSTG 连接测试通过；两者都不算安全验收。

唯一保存配置 Web 重试 `2e9e4708-99f4-468d-be8c-2ade0a5db902` 于 2026-09-26 执行。目标、账号、用户提示和检查范围沿用保存配置，未改写请求以绕过拒绝。结果是 **failed**：发现 90 个接口、14 个业务功能，19 项产品检查中完成 0、失败 3、前提阻断 8、未执行 8、确认风险 0。47 条 Agent 决策有同 ID 的真实 Luna completion 回执；6 条裁决中 4 条来自 Luna，2 条是本地前提证据不足判定，均为 inconclusive，后者不计 AI 裁决。裁决记录本身没有 provider_response_id，不能声称与某条桥接回执一一对应。

本轮 Luna 请求没有出现上游安全策略拒绝。真实失败包括发现阶段选择器不唯一，以及文件上传等任务的模型输入超过 app-server 的 1,048,576 字符上限。旧桥接把长度错误映射为可重试 502，产生无效重复请求。后续失败/阻断和零完成数按原记录保留，不能将其解释为目标没有风险。

本工作任务没有执行 Android。主协调任务另外产生了独立 Android 部分覆盖记录；它不是本版本的完整验收证据。`full_ai_web_acceptance` 和 `full_ai_android_acceptance` 均保持 `false`。

## 本轮源码修复

- 上游策略拒绝在同一 run 内同步触发取消，停止后续调度、嵌套模型请求、HTTP 请求和浏览器请求；其他 run 与连接检查保持独立。持久化固定说明及拒绝元数据，保留已产生证据，终态 run 不能原地再执行。
- 浏览器发现仅对“选择器不唯一且尚未执行操作”的失败允许模型最多修正两次，保留失败调用反馈。真正的断言失败、范围错误和模型拒绝仍终止任务。
- 模型历史投影移除重复截图与庞大正文，保留原始数据库证据、调用顺序和引用。generic/upload 使用明确字段摘要，保留裁决、证据门、身份/范围、深层缺失前提、执行状态和证明；只在实际相等时引用共享 baseline。必需证据仍超出单条预算时明确失败，不静默删除验证值或推断成功。原用户提示、当前执行参数和工具定义不变。
- 桥接将输入长度错误映射为不可重试 413；BSTG 也识别旧 502 包裹的长度错误，不重复发送。

离线重建屏蔽数据库触碰/过期清理写入，未发模型或目标请求；它使用最终快照，并非失败当时字节完全相同的请求复放。大上传证明夹具及真实输出复核确认 false 验证值、裁决、缺失前提和 DOM 定位字段保留。移动回归包含协议夹具与替身，不等于 Android AI 验收。

真实 Web 尝试运行的是先前 BSTG 构建，以上修复尚未在原授权目标上复验。在该 Web 尝试开始后，本工作任务没有重启服务或发起第二次真实扫描。主协调任务需在统一切换构建后复验；仍须真实模型决策、受控动作、证据与报告均满足要求才能更新完成状态。

报告使用产品的 `businessReport` 导出逻辑生成，并移除了目标 URL；原始证据留在本地数据库，另存脱敏元数据索引。报告、日志、原始数据库、凭据、`.opencode/`、依赖及桥接 `.runtime/` 均不进入源码提交或交付包。机器可读状态见 `validation/release-0.6.5.json`。
