## 已定位的断点

1. 工作流规划按语义分数把全站无关接口加入前置步骤，导致已采集到正常请求的搜索测试仍被未采集的上传表单阻断。改为只加入声明依赖与明确选择的步骤；已有身份或请求上下文满足的条件不再补充无关请求。
2. multipart 文件内容的脚本测试原本重复进入普通字段测试器，因无普通请求基线失败；文件脚本测试归入实际发送 multipart 二进制文件的上传执行器。
3. 范围外候选项被计入本轮待办，使完成比例失真。仍可保留已实际执行的任务，但未选择且未执行的候选不进入本轮清单。
4. 翻译层永久缓存首次渲染的文字和属性，React 更新后又被恢复成旧值。现在区分翻译层自己的改写与实际新内容，状态、计数、时间正确推进。
5. Android 操作执行期间缺少可见进度记录；现在先持久化进行中状态，再执行并记录终态。
6. Android 截图与 Appium 串行命令共用等待，长操作期间画面停止。增加独立、单飞、只读 ADB 观察器；过期画面必须显示过期/记录状态。
7. 上传证据未在导出清单中；现已加入，保留摘要和引用，二进制正文及已知凭据脱敏。
8. 自动探索把普通结果文字变化当作新页面，计数器会导致反复点击同一按钮。页面键改为依赖结构和可交互控件，普通正文变化不重置访问记录。
9. mitmproxy 冷启动生成证书比旧等待时间更长；改为限时等待可解析证书，并可靠回收生成进程。
10. API 30 的可写分区 remount 可能要求重启；缺少 AVB 准备会造成 vbmeta 校验失败。只在已明确允许安装系统 CA 的专用本地 AVD 中执行 AOSP remount 流程，并校验重启与证书，失败明确返回。
11. Android 11 的 `dumpsys window windows` 不包含焦点字段，导致观察器无法证明当前应用身份。改为完整 window 输出，实际验收已在 Appium 命令执行期间取得匹配的实时帧。
12. 对象上下文未识别界面提供的 object_id，导致真实 BOLA 对照成功仍被认为缺条件；补齐实际对象字段识别。
13. 业务场景展示层把合法的 com.bstg.acceptance 包名当内部工具文本过滤；包身份改用专用格式校验。
14. 未预绑定域名的设备配置，场景校验错误地拒绝当前授权目标；现在以本次明确授权目标限定范围，其他域名仍被拒绝。
15. Appium XML 可用单引号包住含 JSON 的文字。解析器补齐单双引号、数值实体和属性中大于号的处理，保留密码脱敏；两步真实业务流程重新通过严格页面/网络断言。
16. 模型设置页读取的延迟和错误字段与服务端不同；对齐契约，401 原因和连接延迟可见，空密钥编辑保留原凭据。
17. 上传浏览器执行截图仅嵌在内部证据 JSON 中；改为独立、归属当前测试的画面制品，可从核对页面查看。
18. 浏览器离线不一定立即终止已打开的事件流；现在监听网络状态，关闭旧流、保留已核对快照，恢复时新建流，忽略旧连接的迟到事件。
19. 工作流规划后又无条件追加共享登录引用，重新引入无关请求；删除二次追加。规划读取真实采集合同，缺少请求/参数时持久化具体条件不足原因，不启动猜测请求。

20. 验证码字典中的符号需求原先可能被当成真实验证码发送；当前阻止占位字符串进入直接请求及原生回放，并在证据中列明未执行的业务变体。

## 检查能力的实际边界

- 反射 HTML XSS 和单文件上传脚本：受控目标中实际浏览器观察本轮唯一执行标记，生成可回看的截图和请求证据。
- BOLA：实际 Android 流量、两份隔离会话、双方对象归属及拥有者对照已验证。写操作及未知响应归属结构需要目标专用断言。
- 文件读取/路径遍历、命令注入：实际请求与原生回放链路已验证；自动确认依赖当前实现支持的具体差异信号，不能覆盖所有平台/盲注形式。
- BFLA、金额/订单逻辑、验证码、支付密码、重复提交与状态竞争：实际请求、工作流变异和证据链可执行；通用输入或 200/success/admin/paid 文字不能代替权限矩阵、验证码生命周期和业务状态不变量。缺少这些对照时显示待复核，不确认漏洞或安全。
- 本次未连接外部模型。模型设置 UI 使用明确的协议测试服务验证保存、连接、错误与凭据处理，不声称模型推理质量通过。
