## 关键正反路径

1. 大于旧截断上限的清单完整显示，父级调度任务不冒充具体业务检查。
2. 已完成且确认问题的项目划线，同时问题卡片保持；执行故障不制造漏洞。
3. 缺少基准、原生执行、执行记录或前置条件时不确认；模型一句有漏洞不算确认。
4. 同任务多个来源必须分别核对，最后一个正常结果不能掩盖此前未决结果。
5. App 生产流程实际写入 pending/running/completed，整轮未结束就可读到第一项完成。
6. 预期 401 是正确的业务拒绝结果；缺包、错响应、错 UI、动作失败分别产生失败/未执行状态。
7. 重试在动作开始前清除旧完成状态；一项失败不会把下一项自动划线。
8. 活跃截图只读且同一时间最多一个在途采样；关闭后不继续拍摄，停止后改为记录状态。
9. 截图不能跨运行/任务串用；旧图、没有图片正文、模拟图、未来时间戳均不能证明实时设备操作。
10. SSE 使用真实 Node HTTP 套接字测试重同步与清理；慢读者合并状态，断线不泄漏订阅。
11. 浏览器订阅先于快照；旧 HTTP 响应不能覆盖新事件；切换运行取消旧连接；失败时进入轮询并恢复。
12. 浏览器验证完整清单、删除线、确认问题保留、无图提示、筛选、搜索、App 入口、窄屏无横向溢出，以及问题/报告不请求内部接口。

## 不能推出的结论

不能从上述结果推出所有应用业务都已自主发现、所有攻击类别都覆盖、真实证书信任和抓包已验收、生产 React18/Vite 构建已成功、所有数据库引擎和多实例部署都已验证。数据库适配器测试执行了生产 SQL 路径，但不是生产 better-sqlite3 原生模块或 PostgreSQL 验收。

页面隐藏内部信息不等于新增完整身份认证或租户隔离。原有管理/执行接口仍需受控部署。当前对 Web/API 的安全判定仍由原有执行器负责；新用户视图从其证据投影，不声称零误报。
