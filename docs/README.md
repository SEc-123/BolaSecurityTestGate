# BSTG documentation

Start with the root [README](../README.md) for setup and development commands. The maintained product documents are:

- [Agent execution overview](product/agent-execution.md): how normal-flow learning, native workflows, experiments, and evidence fit together.
- [Browser runtime](product/local-runtime-reuse.md): the project-owned Playwright image and isolated worker setup.
- [HTTPS business capture](product/https-business-capture-contract.md): CA trust, browser capture, native replay, and evidence requirements.
- [Live browser runbook](live-browser/RUNBOOK.md): operation and troubleshooting of the live browser feature.
- [Live browser user pages](live-browser/USER_PAGES_ZH.md): Chinese guide to its UI pages.
- [Mobile lab](../mobile-lab/README.md): mobile test support and its scope.
- [Deployment](../DEPLOYMENT.md): local deployment and service operation.

Tests and acceptance scripts are the source of truth for detailed behavior. Generated test reports, local environment snapshots, and historical implementation notes are intentionally kept out of the public documentation set.
